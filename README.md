# Цветовой конвертер RGB–CMYK–HLS

Веб-приложение для интерактивного выбора и преобразования цвета между моделями RGB, CMYK и HLS.

## Возможности

- выбор цвета из графической палитры;
- точный числовой ввод каждой компоненты;
- плавное изменение каждой компоненты ползунком;
- автоматический пересчёт всех трёх моделей;
- цветной предпросмотр и отображение HEX-кода;
- ненавязчивые предупреждения при обрезании или округлении значений;
- автоматические тесты математических преобразований.

## Архитектура

- `color_math.py` — Model: чистые функции преобразования, не зависящие от интерфейса;
- `controller.py` — Controller/ViewModel: проверка пользовательского ввода и формирование единого состояния цвета;
- `app.py` — View: элементы интерфейса Streamlit;
- `tests/` — автоматические микро-тесты модели и контроллера.

Все преобразования выполняются через RGB как внутреннее представление. При изменении RGB, CMYK, HLS или цвета в палитре контроллер получает новое значение, рассчитывает остальные модели и возвращает согласованное состояние интерфейсу.

## Основные формулы

Для перехода RGB → CMYK компоненты RGB сначала нормируются делением на 255:

```text
K = 1 − max(R, G, B)
C = (1 − R − K) / (1 − K)
M = (1 − G − K) / (1 − K)
Y = (1 − B − K) / (1 − K)
```

Для перехода CMYK → RGB:

```text
R = 255 × (1 − C) × (1 − K)
G = 255 × (1 − M) × (1 − K)
B = 255 × (1 − Y) × (1 − K)
```

HLS рассчитывается через максимальную и минимальную нормированные компоненты RGB. Светлота определяется как `(max + min) / 2`, насыщенность зависит от светлоты, а цветовой тон — от компоненты с максимальным значением.

## Запуск

Требуется Python 3.10 или новее.

### Windows

```powershell
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
streamlit run app.py
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

После запуска браузер обычно откроет адрес `http://localhost:8501` автоматически.

## Автоматические тесты

Из корневой папки проекта выполните:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют контрольные цвета, обратные преобразования и обработку значений вне допустимого диапазона. Например, `RGB(255, 0, 0)` должен преобразоваться в `CMYK(0, 100, 100, 0)` и `HLS(0, 50, 100)`.
